STYLING APPROACH
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  All styling uses Tailwind v4 utility classes directly in JSX.
  No CSS modules. No separate style files per component.

  index.css contains only:
    @import "tailwindcss"   ← loads all utilities
    body defaults           ← bg-[#020617], text-slate-50, antialiased
    .no-scrollbar           ← hides scrollbar on story row

  Tailwind v4 is configured via @tailwindcss/vite (zero config file needed).
